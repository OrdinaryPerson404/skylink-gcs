🔍 第五阶段：用户体验测试与 Bug 修复

全面代码审查，识别并修复关键问题，确保系统稳定可靠。

🐛 已修复 Bug

P0 - sensor 字段重复声明
MainController 中两次声明 SensorChart sensor 导致编译错误。已删除重复声明。
P0 - 地图单击添加两个航点
onMouseReleased 和 onMouseClicked 均调用 clickHandler，导致一次点击添加两个航点。已移除 onMouseReleased 中的点击处理。
P1 - CSS 变量 -fx-text-primary 未定义
地图控制按钮文本颜色引用了不存在的 CSS 变量。已修正为 -fx-text-color。
P1 - 时间窗口切换后 X 轴范围错乱
setTimeWindow 只设置上界不调整下界。已实现根据当前时间动态调整 X 轴范围。
P1 - 通道重新启用后历史数据丢失
禁用通道时清空数据导致重新启用后无历史数据。改为从图表移除 series 但保留数据，禁用通道仍收集数据。
